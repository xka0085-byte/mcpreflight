## What this adds

One row in the third-party extensions table for [mcpdoctor](https://github.com/xka0085-byte/mcp-doctor) — a zero-dependency, MIT-licensed CLI / GitHub Action that runs **read-only** preflight checks against x402 endpoints:

- HTTP 402 challenge presence and status handling
- Payment document shape (x402 v1/v2), including `accepts[]` correctness and vendor-hint headers hiding the real document
- Discovery manifests, latency, response digest

## Scope (stated plainly)

It does **not** sign, pay, settle, retry, or verify delivery. It is a pre-deployment / diagnostics inspector so that server authors catch malformed 402 behavior before an agent's first payment attempt fails.

## Why the extensions table

It is a partner-built package that extends x402's usability without touching the core spec — the same category as the other rows. Happy to reword, move it to a different docs page, or drop any column value that doesn't fit your taxonomy.
