x402 Endpoint Inspector

An x402 endpoint inspector reads the HTTP 402 payment challenge an API returns and validates the payment document (accepts[] entries, discovery manifests, required shapes) without paying, signing, or settling anything. A malformed challenge is how an integrator discovers a broken billing flow only after wiring in a wallet; catching it preflight is the point. mcpreflight inspect prints exactly which step of the challenge diverges from the spec, plus latency, size, and a response digest, all read-only. The command below reproduces any single result.

Read the full guide in the source repository.

npx @eidonze/mcpreflight@0.4.0 inspect https://your-api.example/paid --method=POST --json

Checks HTTP 402, payment documents, v1/v2 accepts[], discovery manifests, latency, size, and response digest. It never pays, signs, settles, or retries.

x402 challenge drift tracking

The same cohort is re-probed read-only every Monday and the 402 challenge shape is fingerprinted per paid resource. A drifted value above zero means at least one serving endpoint changed its challenge shape since the previous run, which is the failure mode buyers hit first. Discovery is partial by design, since /.well-known/x402 is not universal, so discoverable counts only endpoints that publish their paid resources.
