Limits, stated plainly

  • Static schema checks say the tool contract is well-formed. They do not say a tool is useful, correct, or safe.
  • Authenticated endpoints are out of scope: no token is ever used, so a gated server is reported as gated, never as healthy or dead.
  • One snapshot per week. Uptime between scans is not measured — for that, run the CLI or the Action against your own endpoint.
  • 2 registry names are omitted at maintainer request and do not appear in any file here.
