MCP Registry Weekly Pulse

A measured answer to the question everyone asks AI and nobody can source: how many MCP servers are actually alive? Every Monday our scanner runs a read-only handshake (initialize + tools/list, nothing more) against all 9991 endpoints in the official MCP Registry. This page tracks what changed, week over week, with reproducible data.

Latest snapshot (2026-10-12)

  • 4764 endpoints completed a clean anonymous handshake (48%)
  • 41 responded but failed validation
  • 5186 gave no anonymous response, which includes endpoints behind authentication

Method

Full methodology and per-server reports live in the Trust Directory. Reproduce any single check with npx @eidonze/mcpdoctor schema <url>. Raw JSON per server is published next to every report. UNKNOWN is not dead: it means no anonymous handshake was observed within our timeout, and authenticated endpoints are expected to appear here.

Data: mcpdoctor, MIT. Weekly rescan automated via GitHub Actions.
