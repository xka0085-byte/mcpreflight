ERC-8004 Agent Registry Watch

Weekly snapshot of the official ERC-8004 Trustless Agents IdentityRegistry on Ethereum mainnet and Base. Latest: 14425 holders on Ethereum, ? on Base, as of 2026-10-19.

ERC-8004 is the on-chain identity layer for AI agents: a registry where an agent registers an identity token that points to its metadata file and endpoints. As agent registries grow, someone adopting an agent will want to know how the registry itself is growing and moving. This page snapshots the registry counters every Monday, free and keyless, and the week-over-week delta is the signal worth watching. The series lives in trust-data/erc8004-history.json in the repository.
