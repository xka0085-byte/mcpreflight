Diff of the weekly read-only rescan against the previous week (2026-10-30). 0 added, 46 removed, 264 changed status, out of 35327 endpoints. Added and removed are withheld this week because the previous baseline was a truncated crawl.

Added and removed are not comparable this week. The previous baseline covered only 9991 endpoints, from a crawler that stopped after 300 pages. The 25382 endpoints absent from it are endpoints it never reached, not new registrations, so they are not listed. A complete baseline is stored from this run on; added and removed become exact next week.

Every Monday the whole official registry is re-scanned read only and this page diffs the two weeks. A server appearing here as added was not in the registry the week before. Status changed means its anonymous handshake outcome moved, for example from PASS to AUTH_GATED, which is usually an authentication change rather than an outage. The machine-readable feed with the full arrays is at trust-data/registry-changes.json in the repository.
